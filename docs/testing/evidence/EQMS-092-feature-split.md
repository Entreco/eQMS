## Search regression

[Sanitized raw report](EQMS-092-feature-search-ui.json) retains every measured
sample and the exact clean revision, fixture description and executable hash.
Personal paths are replaced with descriptive placeholders.

The existing prepared fixture contains 10,000 current drafts, 104,860,000
current body bytes and 100 historical revisions. Initial fixture generation
was not repeated; see earlier evidence for its preparation cost. This run's
warm no-op preparation took 150.64 ms, separate from query timing.
20 warmups and 100 measured samples per query were retained, with no outliers
removed. Input-to-layout includes 10 ms debounce, real native invocation,
decoding and the result list's Compose layout in feature:search. An empty
initial document-list override excludes workspace opening/full-list load.

| Query | p50 ms | p95 ms | Required p95 |
|---|---:|---:|---:|
| And | 95.96 | 123.10 | <=150 ms |
| risk | 93.78 | 124.35 | <=150 ms |
| managment | 94.40 | 120.23 | <=150 ms |
| trace | 91.01 | 116.96 | <=150 ms |

Synthetic repetitive text, warm caches and one machine are not a production
performance guarantee. These measurements do not establish an improvement
over prior runs.
